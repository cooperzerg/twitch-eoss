# twitch-eoss

Twitch streaming tools for Valorant: OBS scripts, widgets, and chat bot.

## Structure

- `scripts/` - OBS automation scripts (Python/Lua)
- `widgets/` - HTML/CSS/JS stream widgets and overlays
- `bot/` - Twitch chat bot
- `docs/` - Documentation

## Tech Stack

- Python (scripts, bot)
- HTML/CSS/JS (widgets)
- OBS Studio (automation)
